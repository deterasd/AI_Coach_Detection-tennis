# 重心分析功能使用說明 (Body Weight / Center of Mass)

## 概述

重心分析（Body Weight）針對擊球瞬間的膝蓋彎曲程度與擊球後重心前移情況進行分析。分析點 A 與專家（pro）數據比較；分析點 B 為使用者自身擊球前後幀的比較。

---

## 分析時間範圍

| 分析幀 | 說明 |
|--------|------|
| 擊球幀（impact_idx） | `tennis_ball_hit = true` 的幀 |
| 擊球後幀（post_impact） | 擊球幀之後數幀（用於重心前移分析，可為擊球後 5~10 幀的平均或代表性幀） |

---

## 兩點獨立分析

| 分析點 | 分析內容 | 比較基準 |
|--------|----------|----------|
| A | 擊球時膝蓋彎曲（重心高低） | 與專家 P10~P100 比較 |
| B | 擊球後重心前移 | 自我比較（擊球前 vs 擊球後、左膝 vs 右膝） |

---

## 分析方法

### A. 擊球時膝蓋彎曲（重心高低）

**分析標的：**
> 「擊球時兩腳膝蓋要彎曲。球速越快屈膝要越明顯、膝部內角度越小。」

**取點：** `left_hip`、`right_hip`、`left_knee`、`right_knee`、`left_ankle`、`right_ankle`

**計算方法：**
1. 計算膝部內角度（膝關節角度）：
   - 左膝角度：`angle(left_hip, left_knee, left_ankle)`
   - 右膝角度：`angle(right_hip, right_knee, right_ankle)`
   - 角度計算：三點形成夾角，0°~180°（180° = 伸直，角度越小 = 屈膝越多）
2. 取擊球幀的左右膝角度平均（或取兩者中較大者，代表雙腿中較伸直的一側，更能反映重心是否過高）
3. 從 `knn_dataset_new.json` 的 pro 數據計算專家範圍（P10、P90、P100）
4. 比較用戶擊球幀的膝部角度與專家範圍

```python
# 三點夾角計算（餘弦定理）
def angle(p1, p2, p3):
    # p2 為頂點，回傳 p1-p2-p3 的夾角 (0-180°)
    a = distance(p2, p3)
    b = distance(p1, p3)
    c = distance(p1, p2)
    cos_val = (a**2 + b**2 - c**2) / (2*a*b)
    cos_val = max(-1, min(1, cos_val))
    return degrees(acos(cos_val))

# 擊球幀
left_knee_angle = angle(left_hip, left_knee, left_ankle)
right_knee_angle = angle(right_hip, right_knee, right_ankle)
knee_angle_impact = (left_knee_angle + right_knee_angle) / 2  # 或取 max
```

**判斷基準：**
| 條件 | 等級 | 評語 |
|------|------|------|
| 膝部角度 ≤ 專家 P90 | a | 擊球身體重心得宜 |
| P90 < 膝部角度 < P100 | b | 擊球時整體重心略高，建議揮拍時可以微微屈膝 |
| 膝部角度 ≥ 專家 P100 | c | 擊球時整體重心太高，建議揮拍時可以屈膝 |

**建議：**
- 屈膝可穩定下盤，有助於擊球穩定性和力量傳遞
- 揮拍時微微屈膝，好像要坐到椅子上

---

### B. 擊球後重心前移

**分析標的：**
> 「擊球後，右腳膝部內角度要比擊球前大；左腳膝部內角度要比右腳小。代表重心有往前送。」

**取點：** `left_hip`、`right_hip`、`left_knee`、`right_knee`、`left_ankle`、`right_ankle`

**計算方法：**
1. **擊球前**：取擊球幀前數幀（例如前 5 幀）的平均，或擊球幀本身
   - 右膝角度：`right_knee_angle_before`
2. **擊球後**：取擊球幀後數幀（例如後 5~10 幀）的平均或代表性幀
   - 右膝角度：`right_knee_angle_after`
   - 左膝角度：`left_knee_angle_after`
3. 條件 1：`right_knee_angle_after > right_knee_angle_before`（右腿擊球後伸直，重心前移）
4. 條件 2：`left_knee_angle_after < right_knee_angle_after`（左膝比右膝彎，重心落在左腳）

```python
# 擊球前後比較
cond1 = right_knee_angle_after > right_knee_angle_before  # 右腿有伸直
cond2 = left_knee_angle_after < right_knee_angle_after   # 左膝較彎、重心在左
```

**判斷基準：**
| 條件 1 + 條件 2 | 等級 | 評語 |
|-----------------|------|------|
| 兩者皆滿足 | a | 擊球時身體重心往前得宜 |
| 僅滿足其一 | b | 擊球時身體重心往前略不足，建議揮拍時重心要往左腳移動 |
| 兩者皆不滿足 | c | 擊球時身體重心往前明顯不足，建議揮拍時重心要往左腳移動 |

**建議：**
- 擊球瞬間將重心往前送到左腳
- 讓下半身幫助出力與穩定

## 使用方法

### 1. 基本使用

```python
from trajectory_analysis.trajectory_center_of_mass_knn import analyze_center_of_mass

# 執行重心分析

    "trajectory_data.json",
    "knn_dataset_new.json"
)

print(f"信心度: {confidence:.2f}")
```

## 數據要求

### 必要關鍵點

| 分析點 | 必要關鍵點 |
|--------|-----------|
| A | left_hip, right_hip, left_knee, right_knee, left_ankle, right_ankle |
| B | left_hip, right_hip, left_knee, right_knee, left_ankle, right_ankle |

### 專家數據

- 使用 `knn_dataset_new.json` 中 `level == "pro"` 的數據
- 取每位 pro 的擊球幀（`tennis_ball_hit == true`）
- 計算 A 分析點：擊球幀膝部角度的 P10、P50、P90、P100 作為參考範圍
- B 分析點：不與 pro 比較，為使用者自身擊球前後幀的邏輯條件判斷

---

## 專家範圍計算說明

### A. 擊球幀膝部角度
- 從所有 pro 的擊球幀提取左右膝部內角度（hip-knee-ankle 三點夾角）
- 可取平均或 max(左膝, 右膝) 作為該幀代表值
- 計算 P10（下界）、P50（中位數）、P90、P100（最大值）
- **判斷**：用戶數值 ≤ P90 → 得宜；P90 < 用戶數值 < P100 → 略高；用戶數值 ≥ P100 → 過高

### B. 重心前移
- 不與 pro 比較，為**自我比較**
- 條件 1：右膝擊球後角度 > 擊球前角度
- 條件 2：擊球後左膝角度 < 擊球後右膝角度
- 兩者皆滿足 → 得宜；僅滿足其一 → 略不足；皆不滿足 → 明顯不足

---

## 膝部內角度說明

**膝部內角度**（knee internal angle）：由髖-膝-踝三點形成的膝關節夾角。

- **180°**：腿部完全伸直
- **90°**：膝蓋彎曲約 90°（深蹲）
- **角度越大**：膝蓋越直，重心越高
- **角度越小**：屈膝越多，重心越低

---

## 信心度計算

信心度 = 有效分析點數量 / 2

| 信心度 | 說明 |
|--------|------|
| 1.0 | 兩個分析點皆有效 |
| 0.5 | 一個分析點有效 |
| 0.0 | 無有效分析點 |

---

## 與整合分析的關係

`trajectory_integrated_analysis.py` 中會呼叫 `analyze_center_of_mass`（啟用後），將建議放入 `analyses.center_of_mass_advice`，統計放入 `statistics.center_of_mass`，並輸出 `center_of_mass_confidence` 供「各動作分數」的 BodyWeight 使用。

---

## 注意事項

1. **專家數據依賴**：分析結果依賴 pro 專家數據的品質和數量
2. **擊球幀必須存在**：必須有 `tennis_ball_hit == true` 的幀
3. **擊球後幀**：B 分析點需定義擊球後取幀策略（例如後 5 幀平均、後 10 幀等）
4. **座標系統**：依實際 3D 軌跡座標計算角度，需確認 Y 軸方向（通常 Y 越大 = 越低）
5. **持拍手**：以右手持拍為例，擊球後重心前移到左腳；左手持拍則反之
