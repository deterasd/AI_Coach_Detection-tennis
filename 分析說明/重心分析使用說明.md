# 重心分析功能使用說明

## 概述

重心分析功能是一個專門分析網球運動員身體重心位置的智能分析系統。通過分析髖部與踝部的垂直距離差值，評估運動員在擊球過程中的身體重心高度，並與專家數據進行比較，提供針對性的技術改進建議。

## 核心原理

### 重心代理指標

重心分析使用**髖-踝垂直距離差**作為身體重心的代理指標：

```python
重心代理指標 = 平均髖部Y座標 - 平均踝部Y座標
```

其中：
- **平均髖部Y座標**：左右髖部Y座標的平均值
- **平均踝部Y座標**：左右踝部Y座標的平均值

### 分析邏輯

1. **數據提取**：從每幀軌跡數據中提取髖部和踝部的Y座標
2. **特徵計算**：計算髖-踝垂直距離差作為重心指標
3. **專家比較**：與專家數據庫中的重心指標進行比較
4. **高低判斷**：基於統計分析判斷重心是否偏高、偏低或適中
5. **建議生成**：根據分析結果提供具體的技術改進建議

## 技術參數

### 判斷閾值

重心高低的判斷基於與專家數據的統計比較：

```python
height_diff = current_avg - expert_mean

if height_diff > expert_std * 0.5:
    # 重心偏高：高於專家平均 + 0.5個標準差
elif height_diff < -expert_std * 0.5:
    # 重心偏低：低於專家平均 - 0.5個標準差
else:
    # 重心適中：在合理範圍內
```

### 數據處理

1. **數據標準化**：使用 MinMax 標準化處理多個序列
2. **距離計算**：使用平均絕對誤差 (MAE) 計算與專家的距離
3. **統計分析**：基於專家數據的均值和標準差進行判斷

## 數據要求

### 必要關鍵點

- `left_hip`：左髖部座標（需要Y座標）
- `right_hip`：右髖部座標（需要Y座標）
- `left_ankle`：左踝部座標（需要Y座標）
- `right_ankle`：右踝部座標（需要Y座標）

### 數據質量要求

1. **完整性**：至少需要一側的髖部和踝部數據
2. **有效性**：Y座標不能為 null
3. **穩定性**：建議有足夠的幀數以獲得穩定的統計結果

### 數據處理邏輯

```python
# 優先使用雙側數據的平均值
if left_hip_y and right_hip_y:
    mean_hip_y = (left_hip_y + right_hip_y) / 2
elif left_hip_y:
    mean_hip_y = left_hip_y
elif right_hip_y:
    mean_hip_y = right_hip_y

# 踝部數據處理相同
```

## 系統整合

### 與主 KNN 分析的關係

1. **專家選擇**：使用主 KNN 分析選定的專家數據
2. **一致性保證**：確保所有分析點使用相同的專家參考
3. **整合輸出**：與其他分析結果整合成統一的建議

### 分析流程

1. **主 KNN 分析** → 選擇最相近的專家
2. **重心分析** → 使用選定專家進行重心評估
3. **建議整合** → 將重心建議與專家建議合併
4. **結果輸出** → 生成完整的分析報告

## 注意事項

### 使用建議

1. **數據預處理**：確保軌跡數據經過平滑處理
2. **專家數據**：建議使用已通過主 KNN 分析選定的專家
3. **整合使用**：建議與其他分析點一起使用整合分析系統

### 限制條件

1. **2D 限制**：目前只分析 Y 軸（垂直方向）的重心變化
2. **代理指標**：使用髖-踝距離差作為重心的近似指標
3. **專家依賴**：分析質量依賴於專家數據庫的質量

### 故障排除

#### 常見錯誤

1. **"專家未找到"**
   - 檢查專家文件名是否正確
   - 確認 KNN 數據集中包含該專家數據

2. **數據不完整**
   - 檢查軌跡數據是否包含必要的關鍵點
   - 確認關鍵點數據不為 null

3. **分析結果異常**
   - 檢查數據質量
   - 確認專家數據的完整性

## 技術細節

### 核心算法

```python
def _extract_center_of_mass_feature(frames):
    """提取重心特徵"""
    feature_values = []
    for frame in frames:
        # 收集髖部和踝部Y座標
        hips = []
        ankles = []
        
        # 提取左側和右側數據
        if frame.get('left_hip', {}).get('y') is not None:
            hips.append(frame['left_hip']['y'])
        if frame.get('right_hip', {}).get('y') is not None:
            hips.append(frame['right_hip']['y'])
        if frame.get('left_ankle', {}).get('y') is not None:
            ankles.append(frame['left_ankle']['y'])
        if frame.get('right_ankle', {}).get('y') is not None:
            ankles.append(frame['right_ankle']['y'])
        
        # 計算重心代理指標
        if hips and ankles:
            mean_hip_y = np.mean(hips)
            mean_ankle_y = np.mean(ankles)
            feature_values.append(mean_hip_y - mean_ankle_y)
    
    return feature_values
```

### 統計分析

```python
def _analyze_center_of_mass_height(current_seq, expert_features):
    """分析重心高低"""
    current_avg = np.mean(current_seq)
    expert_avgs = [np.mean(seq) for seq in expert_features if seq]
    
    expert_mean = np.mean(expert_avgs)
    expert_std = np.std(expert_avgs)
    
    height_diff = current_avg - expert_mean
    
    # 基於標準差判斷
    if height_diff > expert_std * 0.5:
        return "重心偏高", "降低重心建議"
    elif height_diff < -expert_std * 0.5:
        return "重心偏低", "提高重心建議"
    else:
        return "重心適中", "保持現狀建議"
```
