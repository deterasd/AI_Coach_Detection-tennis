# 擊球後收拍分析功能使用說明 (Follow-through)

## 概述

擊球後收拍分析（Follow-through）針對擊球後的收拍動作進行分析，檢查：
1. 右手腕是否往左肩方向移動
2. 右手腕是否移動到接近左肩高度
3. 球拍頭是否在終點朝下

---

## 分析時間範圍

| 起點 | 終點 |
|------|------|
| 擊球幀（impact_idx） | 右手肘離左肩最近的那一幀 |

**終點定義說明：** 以「右手肘與左肩的 3D 距離最小」的那一幀作為收拍完成幀。比使用「影片最後一幀」更合理，因為每隻影片長度不同，最後一幀可能處於不同動作階段；而手肘離左肩最近代表收拍頂點，與 pro 比較時更具可比性。

---

## 分析方法

**圖片描述：**
> 「擊球後右手腕往左肩方向移動，並抬高至接近左肩高度，球拍頭在終點朝下」

**取點：** `right_wrist`、`right_elbow`、`left_shoulder`、`paddle.top`、`paddle.bottom`（拍頭可選）

**終點幀取得：** 從擊球幀之後掃描至影片結尾，找出 `right_elbow` 與 `left_shoulder` 的 3D 距離最小的那一幀。

**計算方法：**

#### 1. 方向判斷（往左肩）
- 計算起點（擊球幀）右手腕到左肩的 3D 距離
- 計算終點（右手肘離左肩最近幀）右手腕到左肩的 3D 距離
- 終點距離 < 起點距離 = 往左肩方向移動 ✅

```python
start_dist = ||right_wrist_start - left_shoulder_start||
end_dist = ||right_wrist_end - left_shoulder_end||
moved_toward_shoulder = end_dist < start_dist
```

#### 2. 高度判斷（以左肩為基準，使用專家範圍）
- 在終點幀（右手肘離左肩最近幀）計算手腕 Y 與左肩 Y 的差值（絕對值）
- 從 `knn_dataset_new.json` 的 pro 數據計算專家高度差範圍（P10~P90）
- 用戶的高度差在專家 P10~P90 範圍內 = 高度正確 ✅

```python
target_shoulder_y = left_shoulder_end.y
height_diff = |wrist_end.y - target_shoulder_y|
# 從專家數據計算 P10, P50, P90
height_ok = pro_height_range["p10"] <= height_diff <= pro_height_range["p90"]
```

#### 3. 球拍頭路徑判斷（終點拍頭朝下）
- 終點（右手肘離左肩最近幀）判斷拍頭是否朝下
- **簡單判斷方法**：直接比較 Y 值
  - 在座標系統中：Y 越大 = 越低
  - 如果 `paddle.top.y > paddle.bottom.y`，表示拍頭比拍尾低，即拍頭朝下 ✅

```python
# 簡單方法：直接比較 Y 值
paddle_top_y = paddle_top[1]
paddle_bottom_y = paddle_bottom[1]
paddle_head_down = paddle_top_y > paddle_bottom_y  # 拍頭 Y 值 > 拍尾 Y 值 = 朝下
```

## 使用方法

### 1. 基本使用

```python
from trajectory_analysis.trajectory_followthrough_knn import analyze_followthrough

# 執行收拍分析（knn_dataset_path 預設為 knn_dataset_new.json）
suggestion, confidence = analyze_followthrough("trajectory_data.json")

print(f"建議: {suggestion}")
print(f"信心度: {confidence:.2f}")
```

### 2. 詳細分析

```python
from trajectory_analysis.trajectory_followthrough_knn import analyze_followthrough_detailed

# 取得詳細結果
detailed = analyze_followthrough_detailed("trajectory_data.json")

print("收拍分析:", detailed["followthrough_analysis"])
```

### 3. 測試功能

```bash
python3 trajectory_analysis/trajectory_followthrough_knn.py
```

## 數據要求

### 必要關鍵點

| 點位 | 用途 |
|------|------|
| right_wrist | 手腕位置（起點和終點） |
| right_elbow | 右手肘（用於找出終點幀：手肘離左肩最近） |
| left_shoulder | 左肩位置（計算方向、高度、終點幀） |
| paddle.top | 球拍頭頂部（判斷拍頭是否朝下，可選） |
| paddle.bottom | 球拍頭底部（判斷拍頭是否朝下，可選） |

### 關鍵幀

- **tennis_ball_hit**：用於找到擊球幀（起點）
- **右手肘離左肩最近幀**：作為收拍完成幀（終點），由 right_elbow 與 left_shoulder 的 3D 距離最小者決定

### 專家數據

- 使用 `knn_dataset_new.json` 中 `level == "pro"` 的數據
- 取每位 pro 的擊球幀與「右手肘離左肩最近幀」，計算終點手腕 Y 與左肩 Y 的高度差
- 計算 P10、P50、P90 作為參考範圍

## 信心度計算

| 信心度 | 說明 |
|--------|------|
| 1.0 | 分析成功 |
| 0.0 | 數據不足或分析失敗 |

---

## 注意事項

1. **擊球幀必須存在**：必須有 `tennis_ball_hit == true` 的幀
2. **專家數據依賴**：高度判斷依賴 `knn_dataset_new.json` 中 pro 專家的數據
3. **座標系統**：Y 軸向下為正（Y 越大 = 越低）
4. **高度判斷基準**：使用專家 P10~P90 範圍，若無專家數據則回退到固定閾值（150 單位）
