# 擊球拍面角度分析功能使用說明 (Racket-face)

## 概述

擊球拍面角度分析（Racket-face）針對擊球後球的飛出軌跡與地平線的夾角進行分析，作為拍面角度的代理指標，與專家（pro）數據比較。因擊球瞬間球拍關鍵點常遺失，故改用「球過擊球點後飛出去的路徑向量」來間接評估拍面角度。

---

## 分析時間範圍

| 分析幀 | 說明 |
|--------|------|
| 擊球幀（impact_idx） | `tennis_ball_hit = true` 的幀 |
| 擊球後幀（post_impact） | 擊球幀之後數幀（用於計算球飛出軌跡，建議取擊球後 5~15 幀） |

---

## 單一分析點

| 分析點 | 分析內容 | 比較基準 |
|--------|----------|----------|
| 球飛出角度 | 擊球後球軌跡向量與地平線夾角 | 與專家 P10~P100 比較 |

---

## 分析方法

### 球飛出角度（拍面角度代理指標）

**分析標的：**
> 「拍面向量與地平線夾角建議介於 10° 至 -30° 之間；過仰容易飛高出界。因擊球點常遺失球拍，改以球過擊球點後飛出去的路徑向量與地平線夾角來評估。」

**取點：** `tennis_ball`

**計算方法：**
1. 找出擊球幀（`tennis_ball_hit = true`）
2. 取擊球後數幀（例如擊球後 5~15 幀）的球位置
3. 計算擊球後軌跡向量：
   - 起點：擊球幀的 `tennis_ball` 位置（或擊球後第一幀，若擊球幀球為空）
   - 終點：擊球後第 N 幀的 `tennis_ball` 位置（N 可為 10~15，或取多幀擬合直線）
4. 計算軌跡向量與地平線（XZ 平面）的夾角：
   - 水平分量：`horizontal = sqrt((x2-x1)^2 + (z2-z1)^2)`
   - 垂直分量：`vertical = |y2 - y1|`（依座標系調整正負：Y 軸向上為正時，球往上飛則 vertical 為正）
   - 夾角：`angle = atan2(vertical, horizontal)`，單位為度（°）
   - 角度越大：球飛得越高，表示拍面越仰
   - 角度越小或為負：球飛得越平，表示拍面越下壓
5. 從 `knn_dataset_new.json` 的 pro 數據計算專家範圍（P10、P90、P100）
6. 比較用戶球飛出角度與專家範圍

```python
# 擊球後軌跡向量
ball_impact = get_ball_position(frames[impact_idx])
ball_post = get_ball_position(frames[impact_idx + 10])  # 或取多幀平均

dx = ball_post.x - ball_impact.x
dy = ball_post.y - ball_impact.y
dz = ball_post.z - ball_impact.z

horizontal = sqrt(dx**2 + dz**2)
vertical = dy  # 依 Y 軸方向調整

# 與地平線夾角（仰角）
angle_deg = degrees(atan2(vertical, horizontal))
```

**判斷基準：**
| 條件 | 等級 | 評語 |
|------|------|------|
| 球飛出角度 ≤ 專家 P90 | a | 擊球拍面得宜 |
| P90 < 球飛出角度 < P100 | b | 擊球拍面略仰，建議擊球時拍面要微往下壓 |
| 球飛出角度 ≥ 專家 P100 | c | 擊球拍面過仰，建議擊球時拍面要往下壓 |

**建議：**
- 擊球時想像拍面稍微「蓋住球」，讓拍面略向下壓
- 球先往前走再往上過網，避免過仰飛高出界

---

## 座標系與角度方向說明

- **地平線**：XZ 平面（水平面）
- **仰角**：軌跡向量與水平面的夾角，正值表示球往上飛
- **拍面仰**：球飛出角度過大，球弧線過高，易出界
- **拍面下壓**：球飛出角度較小，球飛得較平

**注意**：實際座標的 Y 軸方向需依專案定義確認（Y 向上為正 或 向下為正），計算時需保持一致。

## 使用方法

### 1. 基本使用

```python
from trajectory_analysis.trajectory_racket_face_knn import analyze_racket_face

# 執行擊球拍面角度分析
suggestion, confidence = analyze_racket_face(
    "trajectory_data.json",
    "knn_dataset_new.json"
)

print(f"建議: {suggestion}")
print(f"信心度: {confidence:.2f}")
```

### 2. 詳細分析

```python
from trajectory_analysis.trajectory_racket_face_knn import analyze_racket_face_detailed

# 取得詳細結果
detailed = analyze_racket_face_detailed(
    "trajectory_data.json",
    "knn_dataset_new.json"
)

print("球飛出角度:", detailed["flight_angle_deg"])
print("專家範圍:", detailed["pro_ranges"])
```

### 3. 測試功能

```bash
python3 trajectory_analysis/trajectory_racket_face_knn.py
```

## 數據要求

### 必要關鍵點

| 分析點 | 必要關鍵點 |
|--------|-----------|
| 球飛出角度 | tennis_ball（擊球幀及擊球後數幀） |

### 專家數據

- 使用 `knn_dataset_new.json` 中 `level == "pro"` 的數據
- 取每位 pro 的擊球幀，計算擊球後球軌跡與地平線夾角
- 計算 P10、P50、P90、P100 作為參考範圍

---

## 專家範圍計算說明

- 從所有 pro 的擊球幀開始，取擊球後 N 幀的球位置
- 計算軌跡向量（擊球幀球位置 → 擊球後第 N 幀球位置）
- 計算該向量與 XZ 平面（地平線）的夾角
- 計算 P10（下界）、P50（中位數）、P90、P100（最大值）
- **判斷**：用戶角度 ≤ P90 → 得宜；P90 < 用戶角度 < P100 → 略仰；用戶角度 ≥ P100 → 過仰

---

## 與整合分析的關係

`trajectory_integrated_analysis.py` 啟用後會呼叫 `analyze_racket_face`，將建議放入 `analyses.racket_face_advice`，統計放入 `statistics.racket_face_confidence`，供「各動作分數」的 RacketFace 使用。

---

## 注意事項

1. **球軌跡品質**：依賴擊球後球的偵測穩定性，若球軌跡遺失或抖動，可能影響角度計算
2. **擊球後幀數**：需足夠幀數以建立穩定軌跡，建議至少 5~10 幀
3. **座標系統**：Y 軸方向須與專家數據一致
4. **代理指標**：此分析以球飛出角度間接推估拍面，非直接量測拍面
