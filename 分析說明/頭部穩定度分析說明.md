# 頭部穩定度分析功能使用說明

## 概述

頭部穩定度分析功能是一個專門分析網球運動員在擊球過程中頭部穩定性和眼睛盯球情況的智能分析系統。通過分析右耳與右腰的平行移動、右耳與右眼的相對位置穩定性，以及擊球品質，提供針對性的技術改進建議。

## 核心原理

### 分析要點

1. **右耳點與右腰位置平行移動**
   - 分析擊球前後各10幀中，右耳和右腰在垂直方向（Y軸）的移動情況
   - 計算兩者Y座標的變異數，變異數越小表示平行移動越好

2. **擊球前至擊球出去後5幀，右耳與右眼線距離不變，直線水平角度不變**
   - 分析擊球前10幀到擊球後5幀的區間
   - 計算右耳與右眼之間的距離變化
   - 計算右耳與右眼在水平面（XZ平面）的角度變化
   - 距離和角度變化越小，表示頭部穩定性越好

3. **成功擊球判斷**
   - 檢查擊球瞬間球與手腕的距離
   - 分析擊球前後球的軌跡變化（速度方向改變）
   - 判斷是否成功擊球、打框或揮空拍

## 分析方法

### 核心算法流程

#### 1. 擊球幀偵測

```python
def _find_impact_frame(frames: List[Dict]) -> Optional[int]:
    # 找出標記為 tennis_ball_hit=True 的幀
    for i, frame in enumerate(frames):
        if frame.get("tennis_ball_hit"):
            return i
    return None
```

#### 2. 右耳與右腰平行移動分析

- **計算指標**：
  - 右耳Y座標變異數
  - 右腰Y座標變異數
  - 兩者Y座標差值的變異數

- **評分標準**：
  - 變異數越小，平行移動評分越高
  - 評分範圍：0.0 - 1.0

#### 3. 頭部穩定性分析

- **距離穩定性**：
  - 計算右耳與右眼距離的變異數
  - 變異數 < 50.0 認為穩定

- **角度穩定性**：
  - 計算右耳與右眼在水平面角度的變異數
  - 變異數 < 10.0度 認為穩定

#### 4. 擊球品質判斷

- **方法1：距離判斷**
  - 擊球瞬間球與手腕距離 < 30cm：成功擊球
  - 距離 > 50cm：未擊中球

- **方法2：軌跡變化判斷**
  - 分析擊球前3幀和擊球後3幀的球位置
  - 計算速度方向變化
  - 速度變化 > 20.0：成功擊球
  - 速度變化 > 100.0：可能打框
  - 速度變化不明顯：揮空拍

### 建議生成邏輯

#### 擊球品質建議

1. **成功擊球**：
   - "成功擊球，整體擊球品質佳，維持目前的動作節奏即可。"

2. **打框**：
   - "本次擊球打到球框，建議調整擊球時機，確保球拍中心面迎向來球。"

3. **揮空拍**：
   - "本次揮拍未擊中球，建議在引拍與揮拍過程中保持眼睛盯球，提升擊球準確度。"

#### 頭部穩定度建議

綜合評分計算：
```python
overall_stability = (parallel_score * 0.3 + 
                     distance_stability * 0.35 + 
                     angle_stability * 0.35)
```

1. **評分 >= 0.7**：
   - "頭部穩定眼睛有盯球。"

2. **評分 >= 0.4**：
   - "擊球過程中頭部不穩定，建議揮拍過程中，眼睛盯好擊球點，並維持頭不轉動。"

3. **評分 < 0.4**：
   - "擊球過程眼睛盯球不足，建議揮拍過程中，眼睛盯好擊球點，並維持頭不轉動。"

## 使用方法

### 1. 直接使用頭部穩定度分析

```python
from trajectory_analysis.trajectory_head_stability import analyze_head_stability

# 執行頭部穩定度分析
suggestion, confidence = analyze_head_stability(
    trajectory_data="trajectory/testing_123/testing_(3D_trajectory_smoothed).json"
)

print(f"建議: {suggestion}")
print(f"信心度: {confidence:.2f}")
```

### 2. 使用整合分析系統

```python
from trajectory_integrated_analysis import analyze_integrated_trajectory

# 執行包含頭部穩定度分析的整合分析
result_path = analyze_integrated_trajectory(
    trajectory_data="trajectory/testing_123/testing_(3D_trajectory_smoothed).json",

```

## 參數調整

### 可調整的閾值參數

在 `trajectory_head_stability.py` 中可以調整以下參數：

1. **平行移動分析窗口**：
   ```python
   window = 10  # 擊球前後各取10幀
   ```

2. **頭部穩定性分析範圍**：
   ```python
   start_idx = max(0, impact_idx - 10)  # 擊球前10幀
   end_idx = min(len(frames), impact_idx + 5 + 1)  # 擊球後5幀
   ```

3. **距離穩定性閾值**：
   ```python
   max_distance_variance = 50.0  # 距離變異數閾值
   ```

4. **角度穩定性閾值**：
   ```python
   max_angle_variance = 10.0  # 角度變異數閾值（度）
   ```

5. **擊球品質判斷距離**：
   ```python
   if distance < 30.0:  # 成功擊球距離閾值
   if distance > 50.0:  # 未擊中球距離閾值
   ```

6. **速度變化閾值**：
   ```python
   if abs(post_vel_x - pre_vel_x) > 20.0:  # 成功擊球速度變化
   if abs(post_vel_x - pre_vel_x) > 100.0:  # 打框速度變化
   ```

## 注意事項

1. **數據完整性**：需要確保軌跡數據中包含 `right_ear`、`right_eye`、`right_hip` 等關鍵點
2. **擊球幀標記**：需要正確標記 `tennis_ball_hit=True` 的擊球幀
3. **信心度計算**：如果關鍵點數據不足，信心度會相應降低
4. **參數調整**：根據實際數據分佈情況，可能需要調整各項閾值參數

## 技術細節

### 關鍵點要求

- `right_ear`: 右耳座標 (x, y, z)
- `right_eye`: 右眼座標 (x, y, z)
- `right_hip`: 右腰座標 (x, y, z)
- `right_wrist`: 右手腕座標 (x, y, z)
- `tennis_ball`: 網球座標 (x, y, z)

### 座標系統

- X軸：左右方向
- Y軸：垂直方向（上下）
- Z軸：前後方向

### 計算方法

1. **距離計算**：使用歐幾里得距離公式
2. **角度計算**：在XZ平面（水平面）計算角度
3. **變異數計算**：使用 numpy.var() 計算樣本變異數
4. **評分標準化**：將變異數轉換為 0-1 範圍的評分
