# 擊球點區域分析功能使用說明 (Contact Zone)

## 概述

擊球點區域分析（Contact Zone）針對擊球瞬間球相對於身體的位置（前後/遠近/上下）進行分析，與專家（pro）數據比較，判斷是否在合理範圍內。

---

## 分析時間範圍

| 分析幀 | 說明 |
|--------|------|
| 擊球幀（impact_idx） | `tennis_ball_hit = true` 的幀 |

---

## 三點獨立分析

| 分析點 | 分析內容 | 比較基準 |
|--------|----------|----------|
| A | 前後位置 | 專家 P10~P90 範圍 |
| B | 遠近位置 | 專家 P10~P90 範圍 |
| C | 上下位置 | 專家 P10~P90 範圍 |

---

## 分析方法

### A. 前後位置

**圖片描述：**
> 「球沿著身體面向方向的前/後位置，正值代表在身體前方（迎前），負值代表在身體後方」

**取點：** `left_hip`、`right_hip`、`left_ankle`、`right_ankle`、`tennis_ball`、`left_eye`、`right_eye`（eye 可選）

**計算方法：**
1. 建立身體局部座標系統：
   - `hip_center = (left_hip + right_hip) / 2`
   - `ankle_center = (left_ankle + right_ankle) / 2`
   - `up_axis = normalize(hip_center - ankle_center)`（上下軸）
   - `right_axis = normalize(right_hip - left_hip)`（左右軸）
   - `forward_axis = normalize(cross(up_axis, right_axis))`（前後軸）
2. 計算球相對於髖中心的向量：`ball_local = tennis_ball - hip_center`
3. 投影到前後軸：`depth = dot(ball_local, forward_axis)`
4. **正規化**：將距離除以身高（`body_height = ||eye_center - ankle_center||`，若 eye 不可用則用 `||hip_center - ankle_center||`）以消除體型差異
5. 從 `knn_dataset_new.json` 的 pro 數據計算專家範圍（P10~P90，已正規化）
6. 比較用戶數據（已正規化）是否在專家範圍內

```python
# 建立前後軸
up_axis = normalize(hip_center - ankle_center)
right_axis = normalize(right_hip - left_hip)
forward_axis = normalize(cross(up_axis, right_axis))

# 投影到前後軸
ball_local = tennis_ball - hip_center
depth = dot(ball_local, forward_axis)

# 正規化：除以身高
body_height = ||eye_center - ankle_center||  # 或 ||hip_center - ankle_center||
depth_n = depth / body_height
```

**判斷基準：**
| 條件 | 等級 | 評語 |
|------|------|------|
| 前後位置在專家 P10~P90 內 | 1 | 前後深度在理想區間，擊球時機掌握良好 |
| 位置 < 專家 P10 | 2 | 前後深度偏後，出拍太慢，建議提早迎前擊球 |
| 位置 > 專家 P90 | 3 | 前後深度偏前，出拍太早，建議稍晚迎球 |

**建議：**
- 提早迎前擊球，讓球在身體前方擊中
- 稍晚迎球，不要過早出拍

---

### B. 遠近位置

**圖片描述：**
> 「球沿著髖線方向（左→右）的偏移，正負與持拍手無關，需在建議中結合持拍側解讀（例如右手持拍時，正值通常代表更靠持拍側）」

**取點：** `left_hip`、`right_hip`、`tennis_ball`

**計算方法：**
1. 建立身體局部座標系統（同 A）
2. 計算球相對於髖中心的向量：`ball_local = tennis_ball - hip_center`
3. 投影到左右軸：`lateral = dot(ball_local, right_axis)`
4. **正規化**：將距離除以骨盆寬度（`pelvis_width = ||right_hip - left_hip||`）以消除體型差異
5. 從 `knn_dataset_new.json` 的 pro 數據計算專家範圍（P10~P90，已正規化）
6. 比較用戶數據（已正規化）是否在專家範圍內

```python
# 建立左右軸
right_axis = normalize(right_hip - left_hip)

# 投影到左右軸
ball_local = tennis_ball - hip_center
lateral = dot(ball_local, right_axis)

# 正規化：除以骨盆寬度
pelvis_width = ||right_hip - left_hip||
lateral_n = lateral / pelvis_width
```

**判斷基準：**
| 條件 | 等級 | 評語 |
|------|------|------|
| 遠近位置在專家 P10~P90 內 | 1 | 左右位置在理想區間，揮拍距離掌握良好 |
| 位置 < 專家 P10 | 2 | 左右位置太靠近身體，建議拉開揮拍距離 |
| 位置 > 專家 P90 | 3 | 左右位置太外側，建議靠近身體中心線，保持身體平衡 |

**建議：**
- 拉開揮拍距離，不要讓球太靠近身體
- 靠近身體中心線，保持身體平衡

---

### C. 上下位置

**圖片描述：**
> 「球相對於「雙踝到雙髖」所定義的身體上方向的高低；正值代表高於髖中心，負值代表低於髖中心」

**取點：** `left_hip`、`right_hip`、`left_ankle`、`right_ankle`、`tennis_ball`、`left_eye`、`right_eye`（eye 可選）

**計算方法：**
1. 建立身體局部座標系統（同 A）
2. 計算球相對於髖中心的向量：`ball_local = tennis_ball - hip_center`
3. 投影到上下軸：`height = dot(ball_local, up_axis)`
4. **正規化**：將距離除以身高（`body_height = ||eye_center - ankle_center||`，若 eye 不可用則用 `||hip_center - ankle_center||`）以消除體型差異
5. 從 `knn_dataset_new.json` 的 pro 數據計算專家範圍（P10~P90，已正規化）
6. 比較用戶數據（已正規化）是否在專家範圍內

```python
# 建立上下軸
up_axis = normalize(hip_center - ankle_center)

# 投影到上下軸
ball_local = tennis_ball - hip_center
height = dot(ball_local, up_axis)

# 正規化：除以身高
body_height = ||eye_center - ankle_center||  # 或 ||hip_center - ankle_center||
height_n = height / body_height
```

**判斷基準：**
| 條件 | 等級 | 評語 |
|------|------|------|
| 上下位置在專家 P10~P90 內 | 1 | 上下高度在理想區間，擊球高度掌握良好 |
| 位置 < 專家 P10 | 2 | 上下高度偏低，建議在球上升過程中提早擊球 |
| 位置 > 專家 P90 | 3 | 上下高度偏高，建議擊球時重心降低，讓球下降一些再擊球 |

**建議：**
- 在球上升過程中提早擊球
- 擊球時重心降低，讓球下降一些再擊球

## 使用方法

### 1. 基本使用

```python

# 執行擊球點區域分析
result = analyze_contact_zone(
    "knn_dataset_new.json",

)
```

## 數據要求

### 必要關鍵點

| 分析點 | 必要關鍵點 |
|--------|-----------|
| A | left_hip, right_hip, left_ankle, right_ankle, tennis_ball |
| B | left_hip, right_hip, tennis_ball |
| C | left_hip, right_hip, left_ankle, right_ankle, tennis_ball |

### 可選關鍵點

- `left_eye`、`right_eye`：用於計算更準確的身高（若不可用則回退到使用 hip_center）

### 專家數據

- 使用 `knn_dataset_new.json` 中 `level == "pro"` 的數據
- 取每位 pro 的擊球幀（`tennis_ball_hit == true`）
- 計算 P10、P50、P90 作為參考範圍（已正規化）

---

## 專家範圍計算說明

### A. 前後位置
- 從所有 pro 的擊球幀提取前後軸投影值（`depth`）
- **正規化**：將距離除以身高（`body_height`）以消除體型差異
- 計算正規化後數值的 P10（下界）、P50（中位數）、P90（上界）

### B. 遠近位置
- 從所有 pro 的擊球幀提取左右軸投影值（`lateral`）
- **正規化**：將距離除以骨盆寬度（`pelvis_width`）以消除體型差異
- 計算正規化後數值的 P10（下界）、P50（中位數）、P90（上界）

### C. 上下位置
- 從所有 pro 的擊球幀提取上下軸投影值（`height`）
- **正規化**：將距離除以身高（`body_height`）以消除體型差異
- 計算正規化後數值的 P10（下界）、P50（中位數）、P90（上界）

**正規化的好處**：可以公平地比較不同體型選手的擊球點位置，關注相對比例而非絕對尺寸

---

## 標準化說明

### 標準化時機
- **投影後標準化**：先將球座標投影到局部座標軸得到絕對距離，再除以標準化基準得到相對比例

### 標準化基準
- **前後位置（A）**：使用身高（`body_height`）標準化
- **遠近位置（B）**：使用骨盆寬度（`pelvis_width`）標準化
- **上下位置（C）**：使用身高（`body_height`）標準化

### 標準化作用
1. **消除體型差異**：不同身高、骨盆寬度的人可以公平比較
2. **跨人可比**：將絕對距離轉換為相對比例（無單位或單位為「倍數」）
3. **建立統一基準**：專家範圍以標準化數值表示，適用於不同體型

---

## 注意事項

1. **專家數據依賴**：分析結果依賴 pro 專家數據的品質和數量
2. **擊球幀必須存在**：必須有 `tennis_ball_hit == true` 的幀
3. **座標系統**：使用身體局部座標系統（以雙髖和雙踝建立）
4. **關鍵點完整性**：需要足夠的關鍵點才能建立局部座標系統
5. **eye 關鍵點**：eye 關鍵點是可選的，若不存在則使用 hip_center 作為身高參考點

## 參數與可調整項

- **分位數區間**：預設 P10–P90，可於程式中修改 `p_low`/`p_high` 參數
- **標準化尺度**：骨盆寬度（遠近位置）、身高（前後和上下位置）
