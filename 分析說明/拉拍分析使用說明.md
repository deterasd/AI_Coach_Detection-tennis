# 拉拍分析功能使用說明 (v4: 四點獨立分析版)

## 概述

拉拍分析功能 (v4) 採用四個獨立分析點，針對拉拍準備動作的不同面向分別給予評語，不設置權重整合。

## v4 版本改進重點

### 🎯 四點獨立分析

| 分析點 | 分析內容 | 主要取點 |
|--------|----------|----------|
| A | 側身完整度 | 雙肩、雙腰 |
| B | 右手腕高度 | 右手腕、右肩、右腰 |
| C | 球拍頭朝向 | paddle.top、paddle.bottom |
| D | 拉拍準備時機 | tennis_ball、right_wrist、右肩 |

---

## 分析方法

### A. 側身完整度

**取點：** `right_shoulder`、`left_shoulder`、`right_hip`、`left_hip`

**計算方法：**
1. 檢查四個點是否都有值（若有缺失 = 側身嚴重不足）
2. 計算肩線向量與腰線向量在 XZ 平面的角度
3. 計算兩向量的角度差（越小 = 越平行 = 側身越完整）
4. **與 pro 比較**：從 `knn_dataset_new.json` 取 `level=="pro"` 的拉拍準備幀，計算每位專家的肩腰角度差，取其 P10、P50、P90 作為參考範圍

**判斷基準（與 pro 比較）：**
| 條件 | 等級 | 評語 |
|------|------|------|
| 四點有缺失 | 3 | 拉拍側身嚴重不足夠 |
| 角度差 ≤ 專家 P90 | 1 | 拉拍側身完整 |
| 角度差 略超出專家 P90 | 2 | 拉拍側身略不足夠 |
| 角度差 大幅超出專家 P90 | 3 | 拉拍側身嚴重不足夠 |

**無專家數據時** 回傳「無法比較」。

**建議：** 建議擊球前拉拍準備要轉動側身。

---

### B. 右手腕高度

**取點：** `right_wrist`、`right_shoulder`、`right_hip`

**計算方法：**
- 取得右肩 Y 座標
- 計算右肩-右腰連線的 Y 座標中點
- 檢查手腕 Y 是否在「右肩 Y ~ 肩腰中點 Y」區間內（Y 越大 = 越低）

**判斷基準：**
| 條件 | 等級 | 評語 |
|------|------|------|
| 右肩 Y ≤ 手腕 Y ≤ 肩腰中點 Y | 1 | 拉拍右手腕高度適當 |
| 手腕 Y 不在此區間 | 2 | 拉拍右手腕高度太低 |

**建議：** 建議拉拍準備時可以將手腕舉到胸部位置。

---

### C. 球拍頭朝向

**取點：** `paddle.top`、`paddle.bottom`

**計算方法：**
- 計算球拍方向向量（從 paddle.bottom 到 paddle.top）
- 計算該向量與水平線的夾角（正值 = 拍頭朝上）
- **與 pro 比較**：從 `knn_dataset_new.json` 取 `level=="pro"` 的拉拍準備幀，計算每位專家的球拍角度，取其 P10、P50、P90 作為參考範圍

**判斷基準（與 pro 比較）：**
| 條件 | 等級 | 評語 |
|------|------|------|
| 球拍角度 ≥ 專家 P10 | 1 | 拉拍球拍頭得宜 |
| 球拍角度 < 專家 P10 | 2 | 拉拍掉下來，球拍頭太低 |

**無專家數據時** 回傳「無法比較」。

**建議：** 建議拉拍準備時球拍頭可以指向天空。

---

### D. 拉拍準備時機

**取點：** `tennis_ball`、`right_wrist`、`right_shoulder`、`left_shoulder`

**計算方法：**
1. 找出球落地幀（tennis_ball 的 Y 值最大的幀）
2. 計算身體朝向（從右肩指向左肩 = 面對前方）
3. 計算身體右方（朝向的垂直方向）和後方（朝向的反方向）
4. 檢查手腕是否在身體的右方且後方

**判斷基準：**
| 條件 | 等級 | 評語 |
|------|------|------|
| 手腕在右後方（同時在右方且後方） | 1 | 拉拍準備時間充分 |
| 手腕在右方或後方（只滿足其中一個） | 2 | 拉拍有點慢 |
| 手腕既不在右方也不在後方 | 3 | 拉拍過慢 |

**建議：** 建議提早在球落地彈起時做好拉拍準備動作。

```
trajectory_integrated_analysis.py  # 整合分析系統
```

## 使用方法

### 1. 基本使用

```python
from trajectory_analysis.trajectory_backswing_knn import analyze_backswing

# 執行拉拍分析
suggestion, confidence = analyze_backswing("trajectory_data.json")

print(f"建議: {suggestion}")
print(f"信心度: {confidence:.2f}")
```

### 2. 詳細分析

```python
from trajectory_analysis.trajectory_backswing_knn import analyze_backswing_detailed

# 取得四個分析點的詳細結果
detailed = analyze_backswing_detailed("trajectory_data.json")

print("A. 側身:", detailed["A_body_rotation"])
print("B. 手腕高度:", detailed["B_wrist_height"])
print("C. 球拍朝向:", detailed["C_paddle_direction"])
print("D. 準備時機:", detailed["D_backswing_timing"])
```

### 3. 測試功能

```bash
python3 trajectory_analysis/trajectory_backswing_knn.py
```

## 數據要求

### 必要關鍵點

| 分析點 | 必要關鍵點 |
|--------|-----------|
| A | left_shoulder, right_shoulder, left_hip, right_hip |
| B | right_wrist, right_shoulder, right_hip |
| C | paddle.top, paddle.bottom |
| D | tennis_ball, right_wrist, right_shoulder, left_shoulder, paddle.top |

### 座標系說明

- **Y 軸：** Y 值越大代表位置越低
- **XZ 平面：** 水平面，用於計算側身角度

---

## 信心度計算

信心度 = 有效分析點數量 / 4

| 信心度 | 說明 |
|--------|------|
| 1.0 | 四個分析點皆有效 |
| 0.75 | 三個分析點有效 |
| 0.5 | 兩個分析點有效 |
| 0.25 | 一個分析點有效 |
| 0.0 | 無有效分析點 |

---

## 注意事項

1. **球落地幀偵測：** 使用 tennis_ball 的 Y 最大值來判斷
2. **分析幀選擇：** 優先使用擊球前 5 幀，若無擊球幀則使用球落地幀
3. **四點獨立：** 每個分析點獨立給評語，不進行權重整合
