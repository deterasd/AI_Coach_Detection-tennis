# 擊球出拍轉身分析功能使用說明 (Hitball-swing)

## 概述

擊球出拍轉身分析（Hitball-swing）針對擊球瞬間的身體轉身動作和手腕位置進行分析，與專家（pro）數據比較，判斷是否在合理範圍內。

---

## 分析時間範圍

| 分析幀 | 說明 |
|--------|------|
| 擊球幀（impact_idx） | `tennis_ball_hit = true` 的幀 |

---

## 兩點獨立分析

| 分析點 | 分析內容 | 比較基準 |
|--------|----------|----------|
| A | 轉身動作 | 專家 P10~P90 範圍 |
| B | 右手腕位置 | 高度區間 + 專家夾角範圍 |

---

## 分析方法

### A. 轉身動作

**圖片描述：**
> 「身體加速轉身動作，右肩快速往左肩靠近，右腰快速往左腰靠近。肩線和腰線快速變短至距離差≈0」

**取點：** `left_shoulder`、`right_shoulder`、`left_hip`、`right_hip`

**計算方法：**
1. 計算肩線在 XZ 平面（從上往下看）的投影距離
2. 計算腰線在 XZ 平面的投影距離
3. **正規化**：將距離除以骨盆寬度（XZ 平面投影：`sqrt((rh.x - lh.x)^2 + (rh.z - lh.z)^2)`）以消除體型差異
4. 從 `knn_dataset_new.json` 的 pro 數據計算專家範圍（P10~P90，已正規化）
5. 比較用戶數據（已正規化）是否在專家範圍內

```python
# 計算 XZ 平面投影距離
shoulder_dist_xz = sqrt((rs.x - ls.x)^2 + (rs.z - ls.z)^2)
hip_dist_xz = sqrt((rh.x - lh.x)^2 + (rh.z - lh.z)^2)

# 正規化：除以骨盆寬度（XZ 平面投影，與距離計算一致）
pelvis_width_xz = sqrt((rh.x - lh.x)^2 + (rh.z - lh.z)^2)
shoulder_dist_norm = shoulder_dist_xz / pelvis_width_xz
hip_dist_norm = hip_dist_xz / pelvis_width_xz
```

**判斷基準：**
| 條件 | 等級 | 評語 |
|------|------|------|
| 肩線和腰線距離都在專家 P10~P90 內 | 1 | 擊球時轉身動作得宜 |
| 距離 < 專家 P10 | 2 | 擊球時轉身動作不足 |
| 距離 > 專家 P90 | 3 | 擊球時轉身動作過頭 |

**建議：**
- 擊球時記得轉動腰部和肩膀
- 擊球時肩膀轉動不要過大，身體正面朝向擊球方向後就要變慢停止

---

### B. 右手腕位置

**圖片描述：**
> 「右手腕往前加速超過右肩-腰線，擊至球時右手腕合適位置介於右肩-腰線和左手腕間。高度在膝蓋和肩膀間」

**取點：** `right_wrist`、`right_knee`、`right_shoulder`、`left_shoulder`

**計算方法：**

#### 1. 高度判斷
- 右手腕 Y 要在「右膝 Y ~ 右肩 Y」之間
- （Y 越大 = 越低）

#### 2. 水平位置判斷
- 先定義幾個點：`ls = left_shoulder`（左肩）、`rs = right_shoulder`（右肩）、`rw = right_wrist`（右手腕）、`center = (ls + rs)/2`（肩膀中心點）
- 計算身體寬度方向（XZ 平面）：`body_dir = (ls.x - rs.x, ls.z - rs.z)`  
  - 這個向量是「從右肩指向左肩」在 XZ 平面的投影，代表身體的寬度方向（左右肩連線方向）
  - **注意**：這不是身體正面面向的方向（身體正面面向的方向應該垂直於這個向量）
  - 使用這個方向作為參考基準，用來判斷手腕相對於身體的位置關係
- 計算手腕方向（XZ 平面）：`wrist_dir = (rw.x - center.x, rw.z - center.z)`  
  - 這個向量是「從身體中心點指向右手腕」在 XZ 平面的投影，代表手腕相對於身體的方向（偏前/偏後）
- 計算這兩個 2D 向量的夾角
  - **夾角的作用**：判斷手腕相對於身體寬度方向的位置
    - 夾角小（接近 0°）：手腕在身體後方或側面
    - 夾角適中（例如 45-75°）：手腕在身體前方，位置得宜
    - 夾角大（接近 90° 或更大）：手腕過度前伸
- 從 `knn_dataset_new.json` 的 pro 數據計算專家夾角範圍（P10~P90）

**判斷基準：**
| 維度 | 條件 | 評語 |
|------|------|------|
| 高度 | 在膝蓋~肩膀範圍內 | 高度得宜 |
| 高度 | 太高（Y 太小） | 位置太高 |
| 高度 | 太低（Y 太大） | 位置太低 |
| 夾角 | 在專家 P10~P90 內 | 位置得宜 |
| 夾角 | < 專家 P10 | 位置太前面 |
| 夾角 | > 專家 P90 | 位置太後方 |

**建議：**
- 擊到球時手腕可以在身體前方
- 擊到球時手腕位置拉回來一些

## 使用方法

### 1. 基本使用

```python
from trajectory_analysis.trajectory_hitballswing_knn import analyze_hitballswing

# 執行擊球出拍分析
suggestion, confidence = analyze_hitballswing(
    "trajectory_data.json",
    "knn_dataset_new.json"
)

print(f"建議: {suggestion}")
print(f"信心度: {confidence:.2f}")
```

### 2. 詳細分析

```python
from trajectory_analysis.trajectory_hitballswing_knn import analyze_hitballswing_detailed

# 取得兩個分析點的詳細結果
detailed = analyze_hitballswing_detailed(
    "trajectory_data.json",
```

## 數據要求

### 必要關鍵點

| 分析點 | 必要關鍵點 |
|--------|-----------|
| A | left_shoulder, right_shoulder, left_hip, right_hip |
| B | right_wrist, right_knee, right_shoulder, left_shoulder |

### 專家數據

- 使用 `knn_dataset_new.json` 中 `level == "pro"` 的數據
- 取每位 pro 的擊球幀（`tennis_ball_hit == true`）
- 計算 P10、P50、P90 作為參考範圍

---

## 專家範圍計算說明

### A. 肩腰線距離
- 從所有 pro 的擊球幀提取肩線和腰線的 XZ 平面距離
- **正規化**：將距離（XZ 平面投影）除以骨盆寬度（XZ 平面投影：`sqrt((rh.x - lh.x)^2 + (rh.z - lh.z)^2)`）以消除體型差異
- 計算正規化後數值的 P10（下界）、P50（中位數）、P90（上界）
- **正規化的好處**：可以公平地比較不同體型選手的動作模式，關注相對比例而非絕對尺寸
- **注意**：骨盆寬度使用 XZ 平面投影，與肩腰線距離的計算方式保持一致（都只考慮水平面的變化）

### B. 手腕夾角
- 從所有 pro 的擊球幀計算身體朝向與手腕方向的夾角
- 計算 P10（下界）、P50（中位數）、P90（上界）

---

## 信心度計算

信心度 = 有效分析點數量 / 2

| 信心度 | 說明 |
|--------|------|
| 1.0 | 兩個分析點皆有效 |
| 0.5 | 一個分析點有效 |
| 0.0 | 無有效分析點 |

---

## 注意事項

1. **專家數據依賴**：分析結果依賴 pro 專家數據的品質和數量
2. **擊球幀必須存在**：必須有 `tennis_ball_hit == true` 的幀
3. **座標系統**：Y 軸向下為正（Y 越大 = 越低）
